### Poetry Instructions
1. poetry install

2. Commands to run:
    * poetry run server
    * poetry run migrate
    * poetry run makemigrations
    * poetry run python manage.py runserver (DO NOT USE 127.XXX:8000, USE localhost:8000)

## Project Features

### VGG Latent Space Visualizer
- Latent space is generated by a VGG model and reduced by PCA to a 2D mapping
- Allows exploring the space of pants images by clicking on different regions
- Shows similar pants from the database based on latent space proximity

### GAN Latent Space Visualizer (New!)
- Interactive visualization of pants using StyleGAN3 model
- Allows morphing between different points in the GAN latent space
- Features sliders to modify specific attributes of the generated pants
- Real-time generation of new pants designs by perturbing the latent space

### Technical Details
- Python (Django) handles backend and more intense calculations and fetches
- JS runs the graph and the frontend (simple HTML)
- DropBox is used to host real pants images (since there are a lot)
- GAN model generates synthetic pants images directly in the browser
